# Security Policy

## Supported development line

Security fixes are currently targeted at the NEXORA compatibility branch:

- `nexora/compatibility-edition`

This is an active development branch, not a promise of a production support SLA.

## Reporting a vulnerability

Please do not publish exploit details, credentials, private player data, or weaponized proof-of-concept code in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository owner through a private channel already established with the project maintainers.

Include the affected version or commit, impact, reproduction steps, and any safe logs that help confirm the issue. Remove IP addresses, tokens, passwords, and player-identifying information from logs before sharing.

## Response

Reports will be reviewed as project capacity allows. Do not test vulnerabilities against a live server or any system you do not own or have permission to test.
